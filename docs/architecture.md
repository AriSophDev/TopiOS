# Architecture

## What is TopiOS?

TopiOS is a minimal operating system built from scratch by me. :3

## What is the objective of TopiOS?

The primary goal is to gain a deeper understanding of how hardware and software interact.

The secondary goal is to build a functional operating system capable of playing music.

## What do I want to learn by building it?

I want to transition my software development career toward systems programming and low-level development.

Along the way, I also want to learn more about:

- Computer architecture
- Operating systems
- Memory management
- Filesystems
- Device drivers
- Assembly
- C++

## Project Philosophy

- Learn before copying.
- Understand every line of code.
- Keep the kernel simple and modular.
- Write clean and maintainable code.
- Build one feature at a time.
